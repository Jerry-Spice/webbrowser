# Web Browser

I want to make a simple web browser that can render the text that a website serves. I don't particularly care about rendering images or anything else. I just want the text. 

In order to work on this over time (because this seems like a large project) I'm going to outline what I need to be done and then I'm going to organize the work on Github.

---

## MVP

For this web browser I need to do the following:

1. Make HTTPS requests to website's specified by the user.
2. Create a GUI that allows for a search bar + simple rendering of the text on the webpage.
3. Create a system to parse HTML so that I can read the documents that are sent by the server.
4. I would like to create this in C++.
