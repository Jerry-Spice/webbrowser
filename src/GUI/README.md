jj# GUI 

This section is responsible for showing the actual window of the GUI on the screen. Since I'm writing this code on Windows I'm going to write this GUI using the `windows.h` header.

---

## MVP

1. A resizable window
2. Custom Icon
3. Search bar text field (that also searches when `Enter` is pressed)
4. Search Button
5. View panel with rendered text.

## Supported Elements

In terms of HTML functionality I want to support, I want to support the following:

1. Regular Text
2. Italicized Text (via the `<em>` tag)
3. Bold Text (via the `<strong>` tag)
4. Anchor Tags that redirect the user when clicked.

**For this first version I do not want to support tabs**
